Three workstreams, one evidence trail

The pieces of work this case is made of — each one owned end to end by the member company that delivered it.

01

NL-to-SQL semantic correctness

Schema-aware validation of whether the generated query means what the user actually asked — not merely whether it executes.

02

Golden-dataset benchmarking

A curated set of prompts mapped to expected intent and result sets, giving the model a fixed accuracy reference instead of a moving target.

03

Hallucination & drift gates

Checks for invented columns, tables and joins, plus a regression pipeline that re-runs the golden set on every model update and blocks releases that regress.

04

Classic security surface

Black/grey/white-box penetration testing across application, APIs, infrastructure and cloud, secure code review, and RBAC and multi-tenant isolation verification.

05

AI attack surface — red team

Prompt injection, jailbreaks and guardrail validation, data leakage through the AI layer, and model abuse — mapped against the OWASP LLM Top 10.

06

Audit-ready compliance

Gap analysis against the buyer’s actual regulator, an audit-trail review for AI decisions, and governance context attached to every finding by a certified specialist.

How it came together

Why more tooling would not have closed it

They had already bought scanners and monitoring. A scanner finds known CVEs; it does not decide what to test on a non-deterministic model, build a golden dataset, or recognise a prompt-injection path specific to one schema and one set of business rules. A monitoring platform shows a dashboard; it does not produce a defensible ship / don’t-ship verdict, and it does not remediate what it finds. And no tool maps findings to the EU AI Act, SOC 2 or GDPR, attaches governance context, or assembles an evidence pack an external auditor will accept. The three problems interact: an AI correctness bug becomes a data-leakage incident becomes a compliance gap — precisely the failures that testing each surface in isolation misses. What the client needed was not another tool to run themselves, but one team to own all three surfaces and hand back proof.
